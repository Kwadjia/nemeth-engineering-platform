# @nemeth/domain-types

TypeScript types for the NEMETH API, generated from the backend's OpenAPI
document so the frontend and the API can never disagree about a field.

```
openapi.json   exported by `python -m nemeth openapi` (committed)
src/api.d.ts   generated by openapi-typescript (committed; do not edit)
src/index.ts   hand-written aliases and constants
```

Regenerate after any backend schema change:

```bash
npm run api:types      # export OpenAPI from the API, then compile to TypeScript
```
